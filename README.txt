BIJAY — Creative Developer Portfolio
======================================

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser (or use the Live Server extension).

Before publishing:
- Replace https://github.com/ with your real GitHub profile URL.
- Replace your-email@example.com with your real email.
- Update the project cards so they accurately describe projects you have actually built.
- You can remove the Google Fonts links if you want the page to work without external font requests.

Built with plain HTML, CSS, and vanilla JavaScript. No framework or paid API is required.
